# 🕰️ TIME PORTAL

**MCM의 시간을 건너, 그 시대 속 나를 만나보세요.**

가방 하나를 고르면 AI가 나를 1976년 뮌헨, 2005년 글로벌 도약기, 2016년 스트리트 무드, 그리고 2026년 지금으로 데려다줍니다. 촬영 한 번으로 브랜드 헤리티지 네 시대를 직접 체험하고, 네컷 사진으로 간직할 수 있는 오프라인 부스형 웹 경험입니다.

## 💡 배경

MCM은 1976년 뮌헨에서 시작해 성주그룹 인수 이후 글로벌 브랜드로 성장하고, 스트리트 감성을 흡수하며 지금에 이르렀습니다. TIME PORTAL은 이 브랜드의 시간을 방문객이 "구경"하는 게 아니라 "직접 그 시대 속 자신의 모습"으로 체험하게 만들어, 오프라인 매장/부스에서 브랜드 헤리티지를 몰입감 있게 전달하는 것을 목표로 만들었습니다.


## ✨ 주요 기능

- **시대별 AI 얼굴 합성** — 촬영한 얼굴을 1976·2005·2016 세 시대의 레퍼런스 이미지에 자연스럽게 합성 (gpt-image-2)
- **2026 현재 촬영** — 합성이 아닌 실시간 촬영으로 "지금의 나"까지 포함해 총 4개 시대 완성
- **백그라운드 프리페치** — 사진 선택 즉시 다음 시대 이미지 생성을 미리 시작해 체감 대기시간 최소화
- **네컷(Passport) 자동 합성 + QR 다운로드** — 4개 시대 결과를 디자인 프레임에 맞춰 합성, QR코드 스캔으로 방문객 휴대폰에 바로 다운로드
- **추천 상품 · 장바구니** — 선택한 가방 기반 추천, 로그인 여부에 따라 자동으로 노출 제어
- **관리자 페이지 실시간 튜닝** — 상품/레퍼런스 이미지/시대별 프롬프트 디테일을 코드 배포 없이 admin에서 바로 수정

## 🔧 기술적으로 신경 쓴 부분

- **동시 접속 대응**: 여러 방문객이 동시에 이미지 생성을 요청해도 OpenAI 호출이 몰리지 않도록 세마포어로 동시 실행 개수를 제한하고, 순단/rate limit(429) 에러는 지수 백오프로 자동 재시도하도록 처리
- **체감 대기시간 단축**: 사진 선택이 끝나는 순간 다음 1~2개 시대 이미지를 백그라운드 스레드로 미리 생성 시작 — 방문객이 결과 화면을 보는 동안 다음 시대가 이미 준비됨
- **얼굴 비율 캐싱**: 레퍼런스 이미지의 얼굴 검출(OpenCV Haar Cascade)은 매 생성마다 다시 돌리지 않고 최초 1회 계산 후 DB에 캐싱, 레퍼런스 이미지가 교체될 때만 재계산
- **네컷 프레임 합성**: 디자인팀이 준 프레임 PNG의 투명 영역을 픽셀 단위로 스캔해 정확한 좌표를 추출하고, 사진을 프레임 뒤에 자연스럽게 배치
- **opencv 의존성 충돌 해결**: `opencv-python-headless`와 `opencv-contrib-python-headless`가 동시에 설치되면 `CascadeClassifier`가 깨지는 이슈를 재현·격리해 requirements 정리
- **저장 공간 자동 관리**: 방치된 세션·미선택 사진·고아 파일을 안전하게(방금 촬영 중인 데이터는 보호) 정리하는 관리 커맨드 작성
- **CI/CD 자동배포**: `Main` push → GitHub Actions가 서버에 SSH 접속해 pull·마이그레이션·프론트 재빌드·gunicorn 재시작까지 자동 처리
